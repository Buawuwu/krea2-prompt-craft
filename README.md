# Krea2 提示词工坊 · 安装与结构说明

> **人类阅读文档。agent 通常只自动加载 `SKILL.md`，不读本文件**——改了本文件不会影响 skill 是否生效。
> **当前版本见 `SKILL.md` 的 frontmatter 与 `references/CHANGELOG.md`** —— 本文**不写死版本号**（写了会落后）。本 skill 由 `krea2-megastructure-prompts` v1.0.0 重构而来。

## ⚠️ 内容边界（18+）

- 本仓库含 `references/adult-layer.md`：成人向画面的**技法层**（解剖与行为写法、年龄与分级边界、模型实测记录）。**仅限 18 岁以上使用者、仅限合法的成人向创作。**
- 该层自带五条硬不变量：主体一律成年且显式写出成年年龄 · 不指向真实可识别的人 · **不产出任何未成年人相关写法** · "读起来年幼"的体征与性化写法不得同现 · 内容库不进本 skill。
- 其余分册（巨构 / 都市 / 漫画 / 武侠仙侠 / 真人 / 词表 / 句式 / 镜头光）均为 SFW 技法，可按需只加载其中几册。
- 仓库内不含图像素材、真人身份信息或可识别的个人信息；所有示例是技法与句式，不是内容清单。

## 安装

本 skill 是**纯 Markdown 资源包**：入口是 `SKILL.md`，其余文件按需读取，**不需要任何脚本运行环境、不联网、不调模型**。任何能读本地文件的 agent 都能用（Claude Code / Codex / Cursor / Cline / DSH 等），差别只在"skill 根目录放哪"。

### 通用做法

1. 把整个 `krea2-prompt-craft/` 目录放进你所使用 agent 的 skills 根目录（见下表）；
2. 确认目录名与 `SKILL.md` frontmatter 的 `name` 一致（`krea2-prompt-craft`）；
3. 重新加载 / 重启该 agent 的会话。

| 使用的 agent | 用户级（全局） | 项目级（仅该项目） |
|---|---|---|
| Claude Code | `~/.claude/skills/krea2-prompt-craft/` | `<项目根>/.claude/skills/krea2-prompt-craft/` |
| Codex / 通用 `.agents` 约定 | `~/.agents/skills/krea2-prompt-craft/` | `<项目根>/.agents/skills/krea2-prompt-craft/` |
| DSH | `~/.dsh/skills/krea2-prompt-craft/`（即 `$DSH_HOME/skills`） | `<项目根>/.dsh/skills/krea2-prompt-craft/` |

> 项目根 = 从会话工作目录向上找到的第一个含 `.git` 的目录；找不到时即工作目录本身。
> 上表是常见约定，各 agent 的扫描规则以它自己的文档为准，不保证版本间不变。

### 三条注意事项

1. **必须整目录复制** —— `SKILL.md` 用相对路径引用 `references/`、`assets/`，只拷 `SKILL.md` 会断链。
2. **不要把散落的 `.md` 平铺到 skill 根目录** —— 部分 agent（含 DSH）会把根目录里的平铺 `.md` 也当成一个 skill 加载。备份请放别处。
3. **确认该 agent 支持"按需读文件"** —— 若它只能把 `SKILL.md` 一次性塞进上下文、无法按需读取 `references/`，效果会打折：`SKILL.md` 是索引，词表与分册正文都在 `references/` 里。

### 从 zip 安装

解压 `krea2-prompt-craft.zip`，得到 `krea2-prompt-craft/` 目录，再按上表放置。

> **加载规则（决定哪些文件会占成本）**：多数 agent 的 loader **只自动加载 `SKILL.md` 与根目录的 `*.md`**；**`references/`、`tools/`、`assets/` 里的文件不会被自动加载**——所以词库、变更记录、检查脚本都放在子目录里，**按需才读**。
> **出词后的自查**：`bash tools/check-prompt.sh <稿子.md>`

## 架构：通用层 + 题材分册

**为什么这样分**：一个题材的"通用词库"如果重复写两份，以后改词库就要改两处。所以——

| 层 | 放什么 | 谁在用 |
|---|---|---|
| **通用层** | L1 句式、L2 槽位、通用材质/大气措辞、**L5 光**、**L6 镜头**、L7 媒介、组装模板、通用反模式 | 所有题材共用，**只此一份** |
| **题材分册** | 本册 L1 主体名词、**本册 L2 锚定法**、本册 L3 主材、本册 L4 占据物、本册口味表、本册专属反模式 | 每题材一份 |

**L2 是唯一按题材变化的一层**：巨构锚"大"（尺度锚定），都市锚"真"（时代·地域锚定）。新增题材先问：*这个题材"假"在哪里？* 答出来就是它的 L2。

**判据（何时加一行、何时立新册）**：只有 L5 光 + L7 调色变 → **加一行口味预设**；L1/L2/L3/L4 需要重构 → **立新分册**。

> ⚠️ **维护红线**：题材专属词表**绝不写进** `layer-vocabulary.md`。一旦混入，它会污染所有题材的产出，且每加一个题材都要重读通用层。

## 新增一个题材分册的步骤

1. 在 `references/` 建 `<题材>.md`，标题写清，第一段声明本册的 L2 锚定法与边界。
2. 先写 **L2 锚定法**（本册的"假在哪" + 2–4 种锚定手段）。
3. 再补本册专属的 **L1 主体名词 / L3 主材 / L4 占据物 / 口味预设表 / 专属反模式**。
4. 在 `assets/` 建 `seeds-<题材>.md`，每条种子按七层组装。
5. 回 `SKILL.md` §0 的**路由表加一行**，并把该题材的关键词补进 frontmatter 的 `description`（否则不会被触发）。
6. **不要动 `layer-vocabulary.md` 与 `style-presets.md`**，除非是真正题材无关的补充。
