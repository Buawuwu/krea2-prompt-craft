# 维度「组内基数」策略（中文草稿）

> **性质**：草稿，供用户中文 ComfyUI 提示词体系吸收用。
> **素材来源**：第三方英文 Krea2 教学站 `skills/figure-photo-prompt/references/dimension-select-policy-2026.md`（约 4.4KB）。
> **用途原文口径**：写作前定「每个 group 选几个」——**不是**网站 UI 代码，是**防止把互斥的 L2 peer 写成同时成立**。
> **范围纪律**：只收**记号体系 + 总优先级 + 公共 L1 基数表 + 发型反例/正例 + 自检**；**组合包 / 网站 UI / 跨 skill 分工部分已剔除**（见 §6）。
> **标记**：【外来 · 未验】= 素材内容，未经用户体系实测确认；【未明】= 素材没给。

## 0. 记号体系（保留）

| 记号 | 含义 |
|------|------|
| **S** | 该 group **只 1 个**词（组内互斥） |
| **M(n)** | 该 group **最多 n 个** peer 可同时写 |
| **V** | 跨 group **可叠**（纵向：造型 + 刘海 + 发态） |
| **H** | 同层多 peer（横向：多道具） |
| **X** | **整维单轴**（人种 / 性别 / 尺度） |

**总优先级（已定 · 2026-10-06）**：

```
用户原话 > 本策略填空 > 默认
```

> ✅ **「组合包」一档已删（2026-10-06）** —— 用户体系没有"组合包"概念 → 优先级回到三档。见 §7-1。

**禁止（保留）**：把**同一 group 的多个 S 词写成同时成立**。
素材原例：`黑长直 + 丸子 + 马尾`。

## 2. 发型反例 / 正例（保留）

| 错 | 对 |
|----|-----|
| `黑长直 + 长层次 + 披肩微卷 + 低马尾 + 凌乱丸子` → **五造型同写** | **只 1 个** L2 造型 |
| （无修饰，光秃一个造型名） | `黑长直 + 窗帘刘海 + 风动 + 自然黑` —— **跨 group V**（造型 + 刘海 + 发态 + 发色，是四层叠，不是同槽四词） |

**这张表的判读要点（我把素材的口径说白）**：
- 「错」的根因是**同一个 L2 造型槽里塞了 5 个互斥词**；
- 「对」的第二行看着词也多，但每个词落在**不同的 group**（造型 / 刘海 / 发态 / 发色），靠 **V（跨 group 可叠）** 合法；
- → **自检问句**：这串词是「一个槽里的多个选项」还是「多个槽各一个」？前者砍到一个，后者合法。

## 3. 收到用户「一串 ID」时的处置（保留 · 素材 §1.2）

1. 按 **group** 归类（或按中文名推断槽位）。
2. 同 group 若出现多个 **S** 词 → **只留用户最后点名的那 1 个**，其余丢弃（**已定 2026-10-06：「最后点名」优先于「最具体」**）。
3. 再写正文；释义可写：`已压造型互斥：保留 low_pony`。

> 与用户体系「用户原话 > 本策略填空 > 默认」一致：**用户原话优先，但同一槽内的多条原话也要按 S 压到一条**。素材的取舍规则是「**最后点名 / 最具体**」二选一 —— **已定（2026-10-06）：冲突时以「最后点名」为准**（与库内"用户原话优先"同向）。

## 5. 交付前自检（保留 · 已剔组合包项）

- [ ] 主发型造型 ≤1 · 主大姿 ≤1 · 主场景 ≤1 · 主光型 ≤1 · 主调色 ≤1
- [ ] 妆壳 ≤1 · 表情壳 ≤1
- [ ] 道具/暗示焦点若多，≤ 策略上限且**非互斥硬拗**
- [ ] 未把「纵向叠层」理解成「同槽五个 L2」
- [ ] **成套协调**：场景与光一致 · 材质与场一致 · 道具与锚共现 · 服饰与场景色调呼应
- [ ] 配件最多 **1 件主道具**，且**是场景里本来就有的东西**（原素材「锚生态」提法**已删**）

> 释义（已定 2026-10-06）：道具**必须是该场景本来就有的东西**（自然存在，而非凭空塞入）—— 这就是原素材「锚生态」的全部意思；**该提法已删，只留这条正面写法**。

**素材原文的相关纪律（保留）**：`figure 一帧 1 主 / youth 0–1 主 / erotic 一帧一主纪律不变`。
> 该分档按**题材**给道具上限；用户体系是否沿用此分档【未明】。若不用，可简化为「一帧一主道具」。【外来 · 未验】
