## 2. 七条原则（写「中景」前默念）

| 原则 | 说明 | 英文种子（出词时按 `terms-zh.md` 转中文） |
|---|---|---|
| **重心** | 谁在承重——姿势的第一信息 | `weight on the back foot` / `load on the front supporting leg` |
| **对侧** | 肩髋反向更立体 | `shoulders and hips counter-rotated` |
| **软关节** | 关节锁死＝僵 | `soft knee` / `unlocked elbow` |
| **间隙** | 臂贴死躯干易糊 | `gap of light between arm and torso` |
| **功能优先** | 职业/运动先写任务动作 | `hands on the instrument / tool / hold` |
| **从支撑起摆** | 脚／坐骨／抓点 → 髋 → 脊 → 手 → 头（base → spine → distal） | 见左 |
| **景别匹配** | 远景只写大姿态 | 见左（细部留给近景） |

## 6. 受压痕迹（**受力 ＋ 接触点 ＋ 压痕** —— 第三件 · v2.19.30 立 · **v2.19.33 按八跑升级 · v2.19.36 补两条门禁**）

> **定位**：**通用技法**（跨题材）。与 `adult-layer.md` 的物钉句式同族 —— 物钉给**位置 / 高度**，压痕给**接触面变了什么形**。
> **标级**：**模板 =【仅示意 · n=0 · 助手拟】**；**下面四条门禁 =【已验 · 含换种子】**（2026-10-06 · 外挂 §五 #80 v1→v5-B′ 八跑 · 同档 `rayArtshoot_v5_int8_convrot` · 底图 768×1280 → 二采 1152×1920 · **跨种子 777 / 888 / 999 / 111**）；**§6.3 两条新门禁 =【观测 · n=2~3】**（2026-10-06 · C3 探针 · 同档 · 出口 1152×1920 · 种子 111）。
> **单次跑图的观测一律只进 `CHANGELOG.md` 观测区**，不进本表。

| 件 | 回答什么 | 句式（可照用） |
|---|---|---|
| **受力** | 重量压在哪儿 | `重心整个压在{部位}上` |
| **接触点** | 哪个部位挨着哪件物 | `{部位}踩在{物}上` |
| **压痕** | 那个接触面**变了什么形** | `{物}的{表面}上压出{可指认的形}` |

### 6.1 四条门禁（**【已验 · 含换种子】** · 缺一条压痕就出不来）

| # | 门禁 | 证据（八跑） |
|---|---|---|
| ① | **承载物要先写出来** | 没写鞋 → **拖鞋 / 两只不同款**（v1 / v2）；写出鞋 → **6/6 同款一对**（v3 → v5-B′） |
| ② | **必须写「形」这个字** | 写「一道鞋底的形」→ **出形 3/3**（种子 777 / 888 / 999）；只写「更深 / 更实」→ **不出形**（v4） |
| ③ | **不写「推开 / 弧」这类动作词** | 「把…浮尘**推开一道浅弧**」→ **4/4 出同心圆环**（v2 · v3 · v5-B · v5-B′）；换成「被压实 / 比周围深」→ **3/3 不出** |
| ④ | **承载面必须在画面里可见**（v2.19.36 收紧：还要**不被压着它的东西盖住**，见 §6.3 ⑤） | 同一个「形」：开口箱出在**内底面**（可见）· 闭箱出在**正面**（可见）· **脚踩顶面、接触面被鞋挡住 → 不可判**（v5-B′） |

### 6.2 两条通用前提

1. **压痕要落在"画面里存在的面"上**（同「物锚必须存在」那条：空气 / 悬空 / 画面外都不算）
2. **承载面还要露出来**（＝门禁④）—— **模型把形画在"它看得见的平面"上，不画脚下那一面**：八跑里形分别落在**闭箱正面**与**开口箱内底面**，**没有一次落在脚掌下方**。
   → 要形落在脚下：**把接触面侧过来**（踩台面前缘 / 低机位），或**换成形变会波及可见侧面的承载物**（**软垫 · 雪面 · 沙面**）。

### 6.3 两条新门禁（**【已验 · n=2~3 · 含换种子】** · v2.19.36 立 · **v2.19.37 升格** · 2026-10-06 · 同档 · 出口 1152×1920 · 种子 111 / 113 / 777 / 888）

> **怎么来的**：拿 §6.1 那套去跑另外几条机制的压痕，**两种情形换了三条写法都改不动**；把「成的」与「不成的」并排看，门槛才露出来。原始记账见 `CHANGELOG.md` v2.19.36 观测区。

| # | 门禁 | 成的 vs 不成的（n=2~3） |
|---|---|---|
| ⑤ | **痕迹那块面不能还被「压着它的东西」盖住** —— **正面写法＝让压的物件先离开 / 错开** | ✅ **正面【已验 · n=2】**：手**按过之后抬起来**（指尖离面一个指节）→ 掌印 **2/2 出**（与手掌同形含五指 · 印里露出底面 · 粉被挤开一圈堆在四周）；✅ 错位留在物件已离开的地方（脚已离地 · 印在鞋前一步的面上）；❌ **反面**：痕落在**主体躯干底下**（承重点在身下）×3 全败 · 落在**正被握着的那一段**×3 全败 |
| ⑥ | **写「位移 / 形变」，别写「材质级痕迹」** | ✅ **【可照抄 · n=3 · 含换种子】**（种子 111 / 777 / 888）：**松散材料被抹开 / 踩开、露出下面的面** → 掌形 3/3 · 鞋形 1/3 · 雪坑（换承载物）1/1；❌ 硬面上「亮痕 / 亮带 / 反光差」×3 全败 —— **模型改几何、不改材质** |

### 6.4 两条附带观测（**【观测】** · 只进观测区 · v2.19.37）

1. **模型会把痕自己搬到「看得见的面上」**（n=3）：写「**杠面上**留两道掌印」，三跑**无一落在杠面上**，全画到**台面 / 地面**上 —— 因为手还握着那一段（不满足门禁⑤），它就**就近换一个看得见的面**画。⇒ **落点写错不是不出，是出在别处**（判"出没出"时先看别处有没有）。
2. **脚印要出，鞋不能占着那个位置**（3 中 1）：脚印画在**鞋前方**的那一跑出了（含鞋底花纹）；鞋**正站在粉里**的两跑没出。

**用法**：要压痕 → ① 先把承载物与它的材质写出来（门禁①）② 挑一个**不在主体身下、也不被压着它的东西盖住**的接触面 ③ 写「形」与位移，不写「更亮 / 更实」。**承重点落在躯干底下（坐骨 / 背 / 臀）的姿势，别写压痕 —— 写不出来。**

**一条写法纪律**：压痕**不写程度词**（`一小块` / `一道浅边`），换成**可指认的形**或**相对量**（`比…深一档`）。
