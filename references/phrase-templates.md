# 句式库（带槽位的可复用件）

> **定位**：库的**第三根腿**。`layer-vocabulary.md` 管「**有哪些槽位**」、`terms-zh.md` 管「**词怎么译**」，本件管「**句怎么拼**」。
> **为什么有它**（2026-10-06 · 「很多东西写的太死板了，通用性太差。**我追求的是可复用性**」）：
> 原先库的**复用单位是"整条规则长句"** —— 想复用一条只能整句抄；本件把规则里的**骨架**抽出来，**取件 → 填槽 → 拼装**。
> **判据**：**换任何数值 / 物名 / 部位，句子都不塌 ⇒ 可复用件；一换就废 ⇒ 那是实例，不许进本表。**
> **用法**：定题材 → 取件 → 填槽（取值来源见末列）→ 按形态 A（3–6 句）/ 形态 B（十段）拼装。
> **三条自律**：① **只搬状态、不新增证据** —— 本表**只写状态与出处指针**；`n=` / 判读段位 / 档位这类**细节回出处看，本表不重述、不升级**；② **不替 `terms-zh` 干活** —— 本表只管骨架，词回词表取；③ **证据句不进本表**（实跑原文要保真，进了就被糟蹋）。
> **状态列**：`【已验】`＝库内记过实测（n 与条件去"出处"看）· `【观测】`＝单次观测，**未升格** · `【仅示意】`＝未验。

## 怎么用（把"死板处"换成取件 + 填槽）

| 一次定死的写法 | 取件 → 填槽 |
|---|---|
| `后脚整只踩在脚边一只翻倒的木箱上、箱板离地约三十厘米` | **A1** → `{矮凳}的{凳面}上、{后脚}踩实 —— 高到{膝}只能屈`（想多高填多高） |
| `后脚鞋底在箱板浮尘上压出一道鞋底的形` | **A2** → `{凳面}上压出{一道鞋底的形}`（**先写出鞋**，否则没依附） |
| `米白色的及膝半身裙、布面是细斜纹` | **H4 + B3** → `{半身裙}，{细斜纹}，{布纹}在{侧光}下{起毛边}` |
| `一只手按在髋上、掌心压住髋骨外侧的布料` | **A6** → `{掌心}压在{裙料}的{腰侧}上、{四指}从{外侧}托住` |
| `她的神情温柔而迷离` | **E4 → E1/E3** → `{上眼皮抬起来、瞳孔完整露着}，视线落在{画面里的物}` |
| `墙上不出现任何文字` | **I1** → `{墙上}没有任何{文字}` |
| `小腿被浪雾吞掉` | **I3** → `{画面下缘横着一整条齐膝高的白浪带，从小腿外侧翻过去}` |
